# Capta Academy

PWA de treinamento de captação criado para uso em celular e desktop.

## O que já existe
- Dashboard de evolução
- 6 módulos de treinamento
- 18 aulas práticas
- Quiz por módulo
- XP e progressão
- Desbloqueio sequencial de módulos
- Simulador de objeções e situações de campo
- Ranking demonstrativo pronto para integração com banco
- Perfil e conquistas
- Instalação como PWA
- Cache offline via Service Worker

## Próxima evolução recomendada
- Supabase para login e progresso por profissional
- Ranking real da equipe
- Painel do gestor
- Upload de vídeos, PDFs e comunicados
- Certificado por trilha concluída
- Trilhas separadas por Captador, Liner e Closer
